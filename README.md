# 外来物种哨点

一个简单的个人项目，用来记录和上报身边的外来物种。

## 起源

有时候在路上看到一些奇怪的植物或小动物，想知道它是不是外来入侵物种，但查了半天也找不到一个方便的工具。

所以干脆自己写了一个。

## 功能

- 拍照上传，基于特征匹配提供参考结果，由管理员人工确认
- 在地图上标记发现位置
- 提交给管理员审核，核实后公开显示
- 有积分系统，但只是个彩头，没什么实际用途

## 技术栈

- 微信小程序（原生）
- Node.js 后端 + SQLite 数据库
- 图像特征匹配 + 管理员人工审核

## 说明

这是我自己写着玩的，代码粗糙，功能简陋，别指望太多。

识别结果仅供参考，不构成任何官方认定。

## 运行

```bash
npm install
cp .env.example .env
# 编辑 .env 填入 ZHIPU_API_KEY
node server/index.js
```

然后用微信开发者工具导入 `miniprogram/` 目录。
